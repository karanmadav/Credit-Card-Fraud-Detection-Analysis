# Credit Card Fraud Detection & Prediction

This repository contains a **Python project for detecting and predicting credit card fraud** using machine learning and data analysis techniques.  

The project analyzes credit card transactions, identifies fraudulent activity, and builds predictive models for fraud detection.

---

## **Project Overview**

Credit card fraud is a major concern for financial institutions. This project aims to:

- Analyze credit card transaction data  
- Identify patterns of fraudulent activity  
- Build predictive models to classify transactions as **fraudulent** or **legitimate**  
- Provide insights into transaction patterns and customer behavior  

---

## **Dataset**

The project uses a credit card transaction dataset with features like:

- `Transaction ID` – Unique identifier  
- `Transaction Time` – Timestamp of transaction  
- `Amount` – Transaction amount  
- `Merchant` – Merchant details  
- `Category` – Transaction category  
- `Customer Details` – Age, job, location (if available)  
- `Fraud Label` – 1 = Fraud, 0 = Legitimate  

> Make sure your dataset matches the column names used in the script.

---

## **Features & Analysis**

- **Data Preprocessing:** Cleaning, encoding, and scaling data  
- **Exploratory Data Analysis (EDA):** Visualizations to understand patterns and anomalies  
- **Fraud Detection Models:** Logistic Regression, Random Forest, Decision Tree, etc.  
- **Model Evaluation:** Accuracy, Precision, Recall, F1-score, ROC-AUC  
- **Prediction:** Identify fraudulent transactions
